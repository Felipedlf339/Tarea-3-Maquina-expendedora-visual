## Integrantes
- Javiera Aravena
- Felipe de la Fuente
- Martin García

## Descripción
Aplicación gráfica de una máquina expendedora desarrollada en Java con Swing.
Permite al comprador seleccionar productos y monedas, realizar compras y recibir vuelto
a través de una interfaz gráfica interactiva con eventos de mouse.

## Estructura del proyecto
- `src/org/example/modelo` — lógica del sistema
- `src/org/example/vista` — interfaz gráfica Swing
